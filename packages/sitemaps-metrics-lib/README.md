# @shutterstock/sitemaps-metrics-lib

Shutterstock sitemaps metrics library - Used to create CloudWatch Dashboards for streaming sitemaps.

Published CommonJS entry point: `@shutterstock/sitemaps-metrics-lib`. TypeScript declarations are included.
See the [project documentation](https://github.com/shutterstock/streaming-sitemaps) for usage.
