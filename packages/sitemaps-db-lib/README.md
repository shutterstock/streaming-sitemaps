# @shutterstock/sitemaps-db-lib

DynamoDB database library for Shutterstock streaming sitemaps.

Published CommonJS entry point: `@shutterstock/sitemaps-db-lib`. TypeScript declarations are included.
See the [project documentation](https://github.com/shutterstock/streaming-sitemaps) for usage.
